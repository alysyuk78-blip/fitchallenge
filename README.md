# 🏆 FitChallenge — змагання друзів

Вебдодаток для фіксації фізичних вправ і змагання з друзями: віджимання, присідання,
ходьба (кроки/км), біг та будь-які власні вправи з денними нормами.

## Запуск додатку

```bash
npm install
npm run dev        # http://localhost:3000
```

## Спільний доступ (гра з друзями з різних пристроїв)

Додаток синхронізується через невеликий сервер кімнат (без залежностей, чистий Node.js):

```bash
npm run server     # http://localhost:8787
```

Далі в додатку: **⚙️ Команда і вправи → Спільний доступ** → створіть кімнату й
поділіться 6-літерним кодом. Друзі приєднуються за кодом на своїх пристроях.

### Розгортання сервера в інтернеті (щоб грати з різних міст)

Сервер — один файл `server/server.cjs`, працює на будь-якому Node-хостингу:

- **Render / Railway / Fly.io** (безкоштовні тарифи): команда запуску
  `node server/server.cjs`, порт береться зі змінної `PORT` (сервер її читає сам).
- **Власний VPS**: `node server/server.cjs` + reverse proxy (nginx/Caddy) з HTTPS.

Після розгортання в додатку в полі «Адреса сервера» вкажіть публічну адресу,
напр. `https://fitchallenge.onrender.com`.

> Дані кімнат зберігаються у `server/data/rooms.json`. Безпека: код кімнати — це
> і пароль доступу; не публікуйте його відкрито.

## Можливості

- 💪 Запис результатів (разів / кроків / км / хв / сек) з конфеті та визначенням нового лідера
- 😴 Пропуски дня з причинами: лінь / травма-хвороба
- 🎯 Денні норми min/max на вправу з відхиленнями в рейтингу
- 🏆 Рейтинг з медалями, графіки прогресу, підсумок дня з чемпіоном і конфеті
- 🌐 Синхронізація між пристроями через кімнати (код на 6 символів)
